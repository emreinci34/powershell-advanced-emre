# Changelog

All notable changes to the `NWTC.ResourceGroups` PowerShell module are documented in this file.

## Version 1.1.0

### Added

- Added the new public `Get-ResourceGroupSummary` function.
- Added structured reporting for resource group name, location, and tags.

### Changed

- Updated the module manifest to version `1.1.0`.
- Updated module and lab documentation.
- Improved module import and command testing.

## Version 1.0.0

### Initial Release

- Added the public `New-TestResourceGroup` function.
- Added support for resource group name and project ID parameter sets.
- Added pipeline processing and execution statistics.
- Added `WhatIf`, `Confirm`, verbose output, and module logging.
- Added the initial module manifest and documentation.
